Mobile & Web Deployment

Install on iOS & Android + Publish Online

1. Download App & Mobile PWA Files

Download the self-contained app as index.html along with the PWA manifest and service worker for iOS & Android home-screen installation.

2. Publish Online for Free (Under 2 Minutes)

  1. Put index.html, manifest.json, and sw.js in a folder named ummahsalah.
  2. Fastest (Netlify Drop): Go to app.netlify.com/drop and drag-and-drop your folder to get a live https:// link immediately.
  3. GitHub Pages: Create a GitHub repo, upload the 3 files, go to Settings → Pages, and select the main branch.

Quick Tip — Add to iPhone Home Screen:

Open your live UmmahSalah link in Safari, tap the Share icon (⬆️), and select Add to Home Screen for instant 1-tap countdown access. For a native iOS Home/Lock Screen Widget, wrap with Capacitor + WidgetKit in Xcode.

Android

Open your live https:// link in Chrome, tap ⋮ → Install app. To generate a signed .apk / .aab for Google Play, paste your URL into pwabuilder.com or use Capacitor (npx cap add android).

MacBook Pro (.dmg)

On macOS, open your published URL in Safari → File → Add to Dock, or wrap index.html with Electron / Tauri and run hdiutil create -volname UmmahSalah -srcfolder UmmahSalah.app -ov -format UDZO UmmahSalah.dmg to generate a downloadable .dmg.
